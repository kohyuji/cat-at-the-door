# Cat at the Door v7 그림·음악 최종 목록

v7 게임을 회색 상자로 끝까지 만든 뒤, 코드에서 그림이 빠진 자리를 하나씩 모은 목록입니다. 항목마다 저장할 파일 이름, 크기, 게임 속 위치가 코드 그대로 적혀 있습니다.

- 저장소: https://github.com/kohyuji/cat-at-the-door (브랜치 `v7`)
- 지금 그림 파일: https://github.com/kohyuji/cat-at-the-door/tree/v7/assets
- 지금 게임(회색 상자 상태): https://kohyuji.github.io/cat-at-the-door/v7/
- 같이 보낼 배치도: PNG 13장 (B01~B13), [layout/](layout/) (https://github.com/kohyuji/cat-at-the-door/tree/v7/docs/v7-art/layout). 배경을 그릴 때 그 장의 배치도를 함께 첨부해 주세요.
- 새 파일은 모두 저장소의 `assets/v7/` 폴더에 아래 이름 그대로 넣습니다. 그림이 오면 게임 코드에 연결하는 일은 Claude가 합니다.

서기·걷기 칸의 자세한 규칙 (`r6-people-v2.png` 를 재서 얻은 값):

- 서 있는 사람의 키는 32픽셀(머리 꼭대기가 위에서 30번째 줄, 발바닥이 61번째 줄, 줄은 0부터 셈), 몸 너비는 약 16픽셀입니다.
- 발바닥은 모든 칸에서 61번째 줄에 닿게 그립니다. 게임은 칸의 (24, 62) 점을 바닥 위치로 잡고 4배로 키워 그립니다.
- 옆모습은 모두 오른쪽을 봅니다. 왼쪽은 게임이 뒤집어서 씁니다.
- 앉기 칸은 `r6-people-v2.png` 의 20번 칸처럼 의자를 그리지 않고, 무릎을 굽혀 앉은 몸만 그립니다. 앉을 자리는 배경에 있습니다.

배치도 읽는 법 (B01~B13 PNG):

- 1280×720 위에 게임 코드의 좌표를 2배로 옮겨 그렸습니다. 칸마다 왼쪽 위 좌표와 크기를 적었습니다.
- 파랑 칸: 배경에 그려 넣을 것. 그 자리, 그 크기에 그립니다.
- 주황 칸: 게임이 따로 올리는 소품. 배경에는 그리지 않습니다.
- 빨강 점선: 게임이 올리는 사람. 배경에는 그리지 않고, 그 자리는 사람이 서거나 앉을 수 있는 빈 바닥으로 둡니다.
- 회색 점선: 게임이 글자를 쓰는 자리. 그 자리는 밝고 무늬 없는 면으로 둡니다.
- 바닥 띠(아래쪽)가 있는 장면은 옆에서 본 장면입니다. 사람의 발은 y=684(앉은 사람은 y=600 또는 660)에 놓입니다.
