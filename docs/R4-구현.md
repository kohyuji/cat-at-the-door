# R4 구현 규칙

2026-11-04. 승인된 고객 상담·영업직 생활 경영시뮬을 구현한다.

- Life는 DOM 없는 순수 상태 모델이며 version 4를 저장한다. 현재 상담의 응대 단계까지 직렬화한다. 판정은 확률 없이 고객 필요·제안, 정장 털, 피로, 지각을 검사한다.
- 상담 완료 수당 12,000원 + 계약 수당 12,000원. 매일 `wage:<day>` 거래 한 건으로 지급한다. 미완료 상담은 지급하지 않는다. 마지막 결산은 거래를 합산하며 추가 지급하지 않는다.
- 퇴근 18:00, 추가 상담 +60분, 공용 노트북 +45분, 지각 지연 반영. 장보기 후 귀가 +40분. 교통·식비·주거비 적립 14,000원은 귀가 때 한 번 기록한다. 잔액이 적으면 실제 적립한 금액만 차감한다.
- 처음 생활비 12,000원. 건사료 12,000원/8끼, 습식 15,000원/6끼, 한 끼 포장 3,000원, 돌돌이 4,000원. 겨울 단기 근무 세 장면은 구체적인 수입·장보기·생활비 거래로 이어진다. 임의 현금 리셋 없음.
- 걷기·대사 읽기는 시각을 소비하지 않는다. 긴 행동은 예상 종료 시각을 보여 준다. 슬롯·남은 분 산수 UI 없음.
- 아침/저녁 식사, 하루 물 교체와 잔량, 모래 누적과 청소를 구분한다. 평일 출근과 밤에 모래가 누적된다. 주말은 낮을 보내는 장면 뒤 저녁 밥을 챙긴다.
- 가방 물건·옷별 털·문·커튼은 영속. 후드티 자리는 4일째 사건으로 생긴다. 거실에서 쓰다듬은 결과를 확인한 후 직접 침실로 이동한다.
- 고양이 시점은 문 열림/닫힘 모두 첫 근무 전날과 4일째 밤에 제공한다. 다음 아침 이불 털/인형으로 연결한다. 돌봄 누락 횟수로 조기 종료하지 않는다.
- 첫 근무 기간은 봄 4/11~4/23, 근무일 10일과 주말 2일. 마지막 슈퍼와 직접 정하는 마지막 문 뒤 세션 정산으로 끝난다.

시각·자산은 그래픽 담당이 별도 작성한다. 게임 담당은 공개 계약의 이미지 키·scene=shop·consultation·litter clumps·door 값을 연결한다. 실제 검증 결과는 상위 검토자료/R4-게임-결과.md에 기록한다.
