## 한 줄

"회사에서 인정받으려면 취준 시절의 나를 지워야 한다"고 믿던 사람이, 둘 다 나라는 걸 알고 자기만의 균형을 정하는 열이틀.

모든 새 장치는 하나의 질문을 통과해야 했다. **이것이 보리를 돌보는 일과 내 생활 사이의 균형을 손으로 느끼게 하는가?**

## 정답이 없는 선택

보리에게 필요한 건 "같이 자기"가 아니라 함께한 시간이다. 시간을 주는 방법이 여러 개이고, 각각 내 생활에서 가져가는 것이 다르다.

| 돌보는 방법 | 보리가 얻는 것 | 내가 잃는 것 |
| --- | --- | --- |
| 밤: 문을 연다 | 가장 큰 안심 | 잠. 다음 날 기운(배터리)이 줄고, 화면이 흐려지고, 옷 입는 손이 느려지고, 털이 많다 |
| 밤: 문을 닫는다 | 없음 (보리의 밤으로) | 없음. 대신 보리 마음은 다른 시간에 채워야 한다 |
| 아침: 쓰다듬기 | 배웅하는 하루 | 시계가 세 배 빨리 간다. 지각하면 팀장님 표정이 굳는다 |
| 저녁: 낚싯대 | 노는 시간 | 수습 과제 (면담 평가) |
| 후드티 (3막) | 내 냄새 | 없음. 하지만 혼자서는 부족 |

문은 열기와 닫기 둘뿐이다. 문을 닫아도 나쁜 사람이 아니고, 열어도 착한 사람이 되는 게 아니다.

## 엔딩 8개: 균형의 모양

| 엔딩 | 조건 (위에서부터 먼저 맞는 것) |
| --- | --- |
| 나를 잃은 열이틀 | 팀장님 표정이 바닥이거나 지각 5번 이상 |
| 닿지 않는 문 | 보리와의 거리가 아주 멀어짐 |
| 호떡이 친구 (숨은 엔딩) | 사장님과 호떡 이야기를 나눴고, 면담이 좋았고, 보리와 가까움 |
| 모든 시간의 사람 | 연 밤, 쓰다듬은 아침, 논 저녁이 모두 3번 이상 |
| 후드티의 사람 | 후드티를 문 앞에 두고, 연 밤이 3번 이하 |
| 밤의 사람 / 아침의 사람 / 저녁의 사람 | 셋 중 가장 많이 한 것 |

엔딩 화면에는 열이틀의 기록이 띠로 나온다(문, ☀ 아침, ♪ 저녁, ! 지각). 마지막 줄은 늘 같다. "처음 문을 닫던 밤과 마지막 밤. 같은 문이었다."

## 강의와의 연결

| 주차 | v5에서 |
| --- | --- |
| 3주 입력·움직임·공간 | 문을 끌고, 이불을 누르고, 보리로 거실을 걷는다 |
| 4·7주 선택·트리거·분기 | 문/이불, 보리의 밤 행동 → 다음 날 아침, 9일째 사건, 엔딩 8개 |
| 6주 결핍과 행동 | 인정받고 싶은 나 vs 그 시절의 나를 기억하는 보리 |
| 10주 몰입형 서사 | 프롤로그를 읽지 않고 반복해서 겪는다 |
| 11주 반복과 관점 변화 | 매일 같은 아침 화면이 조금씩 달라지고, 같은 밤을 문 반대편에서 걷는다 |
| 12주 핵심 상호작용 | 꾹 눌러 버티는 이불, 끝까지 떼야 하는 털 |
| 13주 공간과 피드백 | 숫자 대신 기운 배터리, 팀장님 표정, 문틈의 빛, 쌓이는 쥐 인형 |

Florence에서는 "감정을 조작의 변화로 전한다"(3막 돌돌이의 "이 정도면 돼")를, 8번 출구에서는 "같은 장면의 작은 차이로 전한다"(매일 같은 아침 방)를 원리로 가져왔다.

## 테스트

브라우저(Chromium)에서 네 가지 방식으로 처음부터 끝까지 자동 플레이했다. 콘솔 오류 없음.

| 방식 | 엔딩 |
| --- | --- |
| 매일 문을 열고, 쓰다듬고, 논다 | 모든 시간의 사람 |
| 매일 문을 닫고, 과제만 한다 | 닿지 않는 문 |
| 하루씩 번갈아 연다 | 모든 시간의 사람 |
| 문은 닫고 과제를 하지만 보리의 밤에 옷장으로 간다 | 후드티의 사람 |
