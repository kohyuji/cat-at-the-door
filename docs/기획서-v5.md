# Cat at the Door v5 기획서

2026-11-03 · 코휴지 · 스토리텔링의 확장 인터랙티브 미디어 워크샵 2

## 한 줄

"회사에서 인정받으려면 취준 시절의 나를 지워야 한다"고 믿던 사람이, 둘 다 나라는 걸 알고 자기만의 균형을 정하는 열이틀.

모든 장치는 하나의 질문을 통과해야 했다. **이것이 보리를 돌보는 일과 내 생활 사이의 균형을 손으로 느끼게 하는가?**

## 왜 뼈대부터 다시 만들었나

v5 첫 버전은 v4의 뼈대(그림 한 장 + 글 한 줄 + 버튼 두 개)를 그대로 두고 그 위에 색과 설명을 덧칠했다. 그래서 "주황은 보리 쪽, 파랑은 내 생활 쪽" 같은 약속을 글로 외워야 했고, 문을 "끌어서 닫는다"면서 버튼을 눌러도 닫혔고, 지금이 보리 시점인지 내 시점인지를 글자로 알려 줘야 했다.

다시 만든 v5는 **장면이 곧 게임**이다.

- **선택 버튼이 없다.** 화면 속 물건(문, 이불, 재킷, 돌돌이, 낚싯대, 노트북, 보리)을 손가락으로 끌고, 문지르고, 당기고, 누른다.
- **처음 하는 동작은 반투명한 손이 한 번 보여 준다.** 할 수 있는 게 여러 개면 손이 번갈아 가며 보여 줘서, 길이 하나가 아니라는 걸 알게 한다. 가만히 있으면 다시 보여 준다.
- **글은 세상 안에만 있다.** 편지, 휴대폰, 달력, 벽시계, 팀장님과 사장님의 말풍선, 그리고 "야옹", "박박", "쏙" 같은 소리. 장면 사이 카드는 시간만 알려 준다("2년 전 겨울", "월요일 1일째").
- **시점은 카메라로 바꾼다.** 문을 닫으면 카메라가 문을 지나 바닥으로 내려가고, 거대한 문 앞에 뒷모습의 보리가 있다. "지금은 보리"라고 쓰지 않는다.
- **결과는 숫자 대신 그림으로 남는다.** 정장 위 털, 시계를 두드리는 팀장님, 눈 밑 그늘, 문틈으로 밀려 나온 쥐 인형, 문의 긁힌 자국, 문을 열어도 오지 않는 보리.

## 정답이 없는 선택

보리에게 필요한 건 "같이 자기"가 아니라 함께한 시간이다. 시간을 주는 방법이 여러 개이고, 각각 내 생활에서 가져가는 것이 다르다.

| 돌보는 방법 | 보리가 얻는 것 | 내가 잃는 것 |
| --- | --- | --- |
| 밤: 문을 연다 | 가장 큰 안심 | 잠. 피곤이 쌓이면 늦게 일어나 하품하고, 새벽 5시에 얼굴 위의 보리. 다음 날 정장에 털 |
| 밤: 문을 닫는다 | 없음 (보리의 밤으로) | 없음. 대신 보리와의 거리가 조금 멀어진다(후드티를 문 앞에 두면 괜찮다) |
| 아침: 쓰다듬기 | 배웅받는 하루 | 쓰다듬을 때마다 1분. 빨간 칸을 넘기면 지각, 팀장님 표정이 굳는다 |
| 저녁: 낚싯대 | 노는 시간 | 수습 과제 (면담 평가) |
| 후드티 (3막) | 내 냄새 | 혼자서는 부족 |

문은 열기와 닫기 둘뿐이다. 문을 닫아도 나쁜 사람이 아니고, 열어도 착한 사람이 되는 게 아니다. 화면 어디에도 점수나 막대가 없다.

## 엔딩 8개: 균형의 모양

| 엔딩 | 조건 (위에서부터 먼저 맞는 것) |
| --- | --- |
| 나를 잃은 열이틀 | 팀장님 표정이 바닥이거나 지각 5번 이상 |
| 닿지 않는 문 | 보리와의 거리가 아주 멀어짐 |
| 모든 시간의 사람 | 연 밤, 쓰다듬은 아침, 논 저녁이 모두 3번 이상이고 지각 2번 이하 |
| 호떡이 친구 (숨은 엔딩) | 사장님과 호떡 이야기를 나눴고, 면담이 좋았고, 보리와 가까움 |
| 후드티의 사람 | 후드티를 문 앞에 두고, 연 밤이 3번 이하 |
| 밤의 사람 / 아침의 사람 / 저녁의 사람 | 셋 중 가장 많이 한 것 |

마지막 밤에 문을 열었으면 침대에서 같이 자는 그림, 닫았으면 보리 높이에서 본 문 앞이 엔딩 그림이 된다. 아래에는 열이틀의 기록이 띠로 나온다(문, 아침, 저녁, 지각). 마지막 줄은 늘 같다. "처음 문을 닫던 밤과 마지막 밤. 같은 문이었다."

## 강의와의 연결

| 주차 | v5에서 |
| --- | --- |
| 3주 입력·움직임·공간 | 문을 끌고, 이불을 누르고, 보리로 거실을 걷는다 |
| 4·7주 선택·트리거·분기 | 문과 이불, 보리의 밤 행동 → 다음 날 아침, 5일과 9일 사건, 엔딩 8개 |
| 6주 결핍과 행동 | 인정받고 싶은 나 vs 그 시절의 나를 기억하는 보리 |
| 10주 몰입형 서사 | 프롤로그를 읽지 않고 손으로 반복해서 겪는다 |
| 11주 반복과 관점 변화 | 매일 같은 아침 방이 조금씩 달라지고, 같은 밤을 문 반대편에서 걷는다 |
| 12주 핵심 상호작용 | 꾹 눌러 버티는 이불, 끝까지 떼야 하는 털 |

Florence에서는 "감정을 조작의 변화로 전한다"(3막 돌돌이의 "이 정도면 됐다")를, 8번 출구에서는 "같은 장면의 작은 차이로 전한다"(매일 같은 아침 방)를 원리로 가져왔다.

## 테스트

폰 화면 크기(390×700) 브라우저에서, 손가락 동작(끌기, 문지르기, 당기기, 누르기, 탭)만 쓰는 자동 플레이어로 처음부터 엔딩까지 여섯 가지 방식으로 플레이했다. 화면 밖 버튼이나 코드로 장면을 건너뛰지 않았다.

| 플레이 방식 | 엔딩 |
| --- | --- |
| 하루씩 번갈아 문을 열고, 아침엔 쓰다듬고, 저녁은 과제와 놀기를 번갈아 | 모든 시간의 사람 |
| 매일 밤 문을 열고, 저녁은 과제와 놀기를 번갈아 | 모든 시간의 사람 |
| 매일 밤 문을 닫고, 9일 저녁 후드티를 문 앞에 | 후드티의 사람 |
| 가끔 문을 열고, 아침엔 쓰다듬고, 저녁은 주로 과제 | 아침의 사람 |
| 매일 밤 문을 열고, 아침마다 오래 쓰다듬고, 저녁엔 놀기만 | 나를 잃은 열이틀 (지각 8번) |
| 매일 밤 문을 닫고, 쓰다듬지 않고, 저녁엔 과제만, 9일엔 찾다가 그냥 나감 | 닿지 않는 문 |
