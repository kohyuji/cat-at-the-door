# R5 시간 표현에 반영한 공식 사례

- [Nintendo 동물의 숲 New Leaf 전자설명서](https://cdn02.nintendo-europe.com/media/downloads/games_8/emanuals/nintendo_3ds_2/animal_crossing_new_leaf_2/ElectronicManual_Nintendo3DS_AnimalCrossingNewLeaf_EN.pdf), 8쪽: 날짜·계절을 기기 시계와 연결한다. 숫자 시각과 생활 환경을 같은 시간에 묶는 근거로 참고했다.
- [EA The Sims 4 공식 팁](https://www.ea.com/games/the-sims/tips-and-tricks?isLocalized=true)의 검색 색인 및 [공식 플레이어 가이드](https://cdn-assets-ts4.pulse.ea.com/Guide/TheSims4_Players_Guide.pdf) 시간 조작 항목: 정지와 보통/빠름/매우 빠름을 구분한다. 대사·메뉴에서 시간이 멈추고 행동 중에는 진행한다는 구분을 플레이어가 인지하도록 참고했다. 가이드 PDF 본문 재요청은 502였고 검색 색인의 공식 항목으로 확인한 범위만 사용했다.

이 게임의 적용은 위 게임을 그대로 복제한 방식이 아닌 설계 판단이다. 계속 걷는 시간 압박은 넣지 않고, 직접 돌봄·휴식·상담을 마칠 때 시계 바늘과 실제 숫자를 함께 약1.3초 움직인다. 같은 보간 시각을 창밖 빛에 제공하며 하루 빛 띠의 위치도 이동한다. 짧은 경과 문구가 어떤 행동 때문에 시간이 갔는지 알려 준다. 마치면 HH:mm만 덧붙이는 기존 문구는 제거했다.
