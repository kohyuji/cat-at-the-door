# 집과 회사에서 보내는 첫 두 주

이 문서는 현재 수정본의 진행과 규칙을 정리한다. 실행과 조작법은 [처음 읽기](../README.md), 공개 주소와 갱신 방법은 [배포 안내](배포안내.md)에 있다.

## 시작과 첫 출근

채용에 떨어졌다는 알림을 읽고 휴대폰을 넣으려던 날, 비를 맞는 고양이를 만난다. 우산을 기울여 비를 막아 주고 편의점에서 고양이용 사료를 산다. 아직 고양이를 모르는 첫 구매에서는 취향이나 평소 먹던 사료를 단정하지 않는다. 이때 회사 준비나 다른 날의 할 일은 표시하지 않는다.

집에 데려온 뒤 이름을 짓고 밥과 물을 직접 준다. 쓰다듬은 뒤 후드티에 붙은 털을 보고 잠자리를 정한다. 첫날부터 방문을 열고 잘 수도, 닫고 잘 수도 있다. 문을 실제로 움직인 뒤 선택을 확정한다.

함께 지내는 시간이 지난 다음 합격과 첫 출근 안내가 온다. 고양이를 데려온 날과 출근 전날을 구분하며, 그때부터 출근복과 가방을 챙긴다.

## 집에서 보내는 시간

평일에는 큰 활동을 고를 저녁 칸이 두 개 있다. 주말에는 오전부터 네 칸을 쓴다. 늦게 돌아온 날은 저녁 한 칸만 남는다. 화면에는 남은 분을 합산하는 숫자 대신 현재 시간대와 채워지는 칸을 보여준다.

밥·물·옷 입기·가방 들기는 큰 활동 칸을 쓰지 않는다. 놀이·휴식·가방 미리 챙기기·빨래·설거지·자리 만들기 같은 활동이 한 칸을 쓴다. 필수 돌봄은 칸을 다 쓴 뒤에도 할 수 있다.

| 장면 | 직접 하는 조작과 결과 |
| --- | --- |
| 밥과 물 | 봉지·물병을 그릇 위로 가져간다. 내용물이 차고 고양이가 먹거나 마신다. |
| 놀이 | 쥐 인형을 움직이고 멈춰 고양이가 따라오고 잡게 한다. |
| 쓰다듬기 | 손을 누른 채 등을 여러 번 쓸어 준다. 고양이와 사람의 반응을 같은 장면에서 본다. |
| 가방 준비 | 노트북·충전기·수첩을 가방에 넣는다. 회사 문서를 집에서 다시 푸는 과제는 없다. |
| 빨래와 설거지 | 주말에 옷을 모으고 접시를 닦는다. 활동 뒤 시간대가 바뀐다. |
| 정장과 보리 자리 | 옷을 걸고 보리가 쉴 후드티나 상자 자리를 마련한다. |
| 잠자리 | 문을 잡고 끝까지 열거나 닫는다. 틈의 크기를 재는 규칙은 없다. |

밥·물·놀이·내 휴식은 체크리스트에서 확인한다. 목록은 접을 수 있다. 사물마다 다음 행동을 긴 글로 붙이거나 상단에 모든 지시를 늘어놓지 않는다.

## 회사가 차지하는 분량

회사 일은 주인공의 낮을 보여 주고 집에 돌아올 시간과 피로에 영향을 준다. 매일 복잡한 문서를 풀게 하지 않는다.

날짜별 파일 분류는 두 번만 직접 한다. 9월 15일에는 `0911·0914·0915`, 9월 22일에는 `0921·0922·0923` 파일을 같은 날짜 폴더에 넣는다. 나머지 근무일에는 메일·동료와 확인·점심·오후 업무를 짧은 장면으로 이어 보여 준다. 업무를 마치면 회사 시각은 퇴근 시간으로 바뀐다.

9월 17일에는 팀장이 내일 오전까지 볼 문서 한 장을 부탁한다. 오늘 마치고 갈지, 내일 출근해서 먼저 할지 선택한다. 선택에 따라 어느 날 귀가가 늦어지는지가 달라진다. 금요일 팀 회의에서는 처음 맡은 일을 짧게 이야기한다. 별도 상품·판매 직무나 사장님의 고양이 에피소드는 없다.

팀장과 동료는 실제 대화만 한다. 작업 결과를 설명하는 문장을 팀장의 반말 대사로 붙이지 않는다. 동료가 고양이 이름을 말하기 전에는 주인공이 직접 소개한 대화가 있어야 한다.

## 돌봄과 일의 결과

아침에 비워 둔 그릇과 저녁 돌봄은 각각 기록한다. 밤에 밥을 보충하면 그 밤의 행동으로 남고, 다음 아침 준비 시간과 식사 상태는 따로 시작한다. 잠에서 깬 장면에는 새벽 표시와 어두운 방을 함께 보여 준다.

먹이지 않은 상태가 반복되면 고양이가 그릇과 주인공 사이를 오가다가, 나중에는 먼저 다가오지 않는다. 음식을 주고 돌봄을 다시 챙기면 상태를 회복할 수 있다. 누락을 오래 방치하면 일정을 바꾸고 돌봄부터 다시 챙기는 결과로 이어진다. 관계 점수나 엔딩 기준 숫자는 플레이어에게 표시하지 않는다.

가방을 놓고 오거나, 맡은 일을 마치지 못하거나, 선택한 추가 업무를 하면 퇴근이 늦어진다. 그날 집에서 고를 활동이 줄어들고 피로가 쌓인다. 미완성 업무는 다음 근무일에 다시 확인해야 하며, 전날 잃은 저녁까지 되돌리지는 않는다. 반복해서 일을 미룬 결과는 마지막 회의에도 반영한다.

익숙한 잠자리와 놀이를 챙겼다면 방문을 닫고 자는 것도 가능한 생활 방식이다. 열린 문 하나만으로 모든 결과를 결정하지 않는다.

## 생활용품과 사료

처음에는 생활비 58,000원이 있다. 건사료는 12,000원에 8끼, 닭고기 습식은 15,000원에 6끼, 한 끼 포장은 3,000원이다. 아침과 저녁을 챙길 양을 살 수 있도록 구성했다. 첫 구매 이후에만 먹이던 사료와 취향을 구분한다. 좋아하는 음식은 즉각적인 반응을 바꾸며 관계 점수를 사는 물건으로 쓰지 않는다.

돌돌이는 첫 출근 뒤 소매에 붙은 털을 본 동료 대화와 귀가 때 구입 안내로 소개한다. 한 번 사면 옷걸이 옆에 남고 이후에도 계속 사용할 수 있다. 접착면 장수나 리필 비용은 세지 않는다. 직장 동료에게 사료나 돈을 부탁하지 않는다.

## 화면과 저장

본문·대화·휴대폰·그림 안 글씨는 DOS 고딕을 사용한다. 시작·이어하기를 누르면 소리가 켜지고 스피커 아이콘으로 끌 수 있다. 시작 화면만 열었을 때는 재생하지 않는다.

저장 메뉴에서 저장, 저장하고 시작 화면으로 돌아가기, 처음부터 시작하기를 고른다. 새로운 시작은 기존 기록을 지운다는 확인을 거친다. 자동 저장도 유지한다. 저장 데이터는 브라우저 안에 있으며 기기 사이에 자동 공유하지 않는다.

현재 코드와 그림은 `src/`·`assets/`, 현재 문서는 `docs/`, 예전 자료는 `archive/v4/`에 둔다. `npm run build`로 웹 실행 파일을, `npm run review`로 그림과 글꼴을 포함한 단일 HTML을 만든다.

구현 사실과 검증 결과는 [확인 기록](생활과돌봄-검토.md)에서 구분한다.
