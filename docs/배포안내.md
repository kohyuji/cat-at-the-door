# 배포 안내 (v6)

GitHub Pages는 `gh-pages` 브랜치에서 나갑니다. v6부터 대표 주소 https://kohyuji.github.io/cat-at-the-door/ 의 루트에는 main(v6)의 빌드가 올라갑니다.

| gh-pages 경로 | 내용 | 누가 바꾸나 |
| --- | --- | --- |
| 루트 | main(v6) 빌드 | main의 `tools/deploy-pages.cjs` |
| `v4.1/` | 예전 대표 주소의 v4.1 | 바꾸지 않음 |
| `claude-v5/`, `codex-v5/`, `codex-v5-claude/` | v5 실험 판 | 각 브랜치의 배포 도구 |

1. main에서 검사하고 커밋한 뒤 `git push origin main`으로 올립니다. 강제 푸시하지 않습니다.
2. `node tools/deploy-pages.cjs --prepare-only`는 캐시된 origin/gh-pages를 바탕으로 루트만 바꾼 묶음을 만들어 검사합니다. 위 표의 다른 폴더가 하나라도 달라지면 멈춥니다.
3. `node tools/deploy-pages.cjs`는 깨끗한 작업 폴더와 origin/main이 같은지 확인하고, 원격 gh-pages를 새로 받아 같은 검사를 한 번 더 한 뒤 그 커밋 위에 푸시합니다.
4. 처음 v6를 올릴 때 루트에 있던 v4.1 파일은 `v4.1/`로 옮겨 둡니다. 그 뒤로는 `v4.1/`도 건드리지 않습니다.
5. 공개 사이트의 `__build.json`에 올린 main 커밋이 적힙니다.

게임 저장은 브라우저 저장소의 `catdoor-v6-save` 키를 씁니다. 같은 github.io 주소 아래 다른 판과 저장이 섞이지 않습니다.
