# 배포 안내

사용자 승인 범위는 원격 codex-v5와 공개 /codex-v5/다. main과 타 작업자 브랜치는 바꾸지 않는다.

1. 작업 브랜치에서 검증하고 소스를 커밋한다.
2. `git push origin HEAD:codex-v5`로 승인된 소스를 올린다. 강제 푸시하지 않는다.
3. `node tools/deploy-pages.cjs --prepare-only`는 캐시된 origin/gh-pages를 기반으로 자기 codex-v5/만 교체한다. 다른 경로와 루트의 Git blob/tree가 바뀌면 중단한다.
4. `node tools/deploy-pages.cjs`는 원격 gh-pages를 새로 가져오고 같은 보존 검증을 한 번 수행한 뒤 그 커밋의 자식으로 푸시한다. 동시 갱신은 일반 푸시의 fast-forward 검사가 막는다.
5. GitHub Pages 성공과 공개 __build.json의 source_commit, index/필수 자산 응답을 API로 확인한다.

기존 gh-pages는 다른 작성자의 여러 사이트를 담고 있다. main에서 gh-pages를 다시 만들거나 gh-pages 전체를 dist로 덮어쓰지 않는다. 기존 루트·다른 모든 디렉터리는 그대로 보존한다. 빌드 자산은 tools/assets.cjs에서 웹·단일 HTML에 공통으로 포함한다.

Git Credential Manager 인증만 사용한다. 토큰은 출력하거나 파일에 저장하지 않는다. 화면 로그인·브라우저 쿠키 추출은 하지 않는다.
