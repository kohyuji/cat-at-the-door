# v4에서 이어지는 경험 확장 검토본

2026-11-03 · `codex/v4-experience`

## 사용자와 맞춘 기준

중심은 내 생활과 고양이를 돌보는 것 사이의 균형, 죄책감, 책임감이다. 이를 전달하는 데 필요하면 구조·규칙·엔딩도 바꿀 수 있다. 이번에는 v4.1의 갈등과 경제 규칙에서 출발해 장면과 행동을 확장했다.

v5에 대한 구체적인 피드백은 설명 부족, 버튼과 조작의 중복, 알아보기 어려운 그림, 납득하기 어려운 새 규칙, 다음 장면까지 넘어가는 연속 클릭, 호떡이와 회사 장면의 맥락 부족이었다.

## 여섯 피드백의 반영

| 피드백 | 이번 검토본 |
| --- | --- |
| 클릭 반복과 조작감 | 방 안의 문·침대에서 선택한다. 문 끌기, 고양이 관점의 인형 밀기, 옷장 조사와 후드티 선택을 추가했다. 돌돌이 조작은 이어 쓴다. |
| 가독성과 선택의 의미 | 설명을 남기고 상황별로 나눴다. ‘들이고 같이 잔다 / 문을 닫아 두고 혼자 잔다’로 행동과 결과를 함께 적었다. 같은 행동을 화면 밖 버튼으로 반복하지 않는다. |
| 고양이 입장 | 첫 거절, 옷장, 비 오는 밤, 처음 멀어진 밤에 고양이 쪽 장면을 경험한다. 고양이 관점의 조작 자체는 관계 수치를 회복시키지 않는다. |
| 사건과 내러티브 | 천둥 → 기척 찾기 → 발견 후 선택, 닫힌 문 → 옷장 → 정장에 남은 털 → 후드티, 사장님 예고 → 털 발견 → 호떡이 사진 → 팀장님 반응으로 이어진다. |
| 볼륨 | 열 밤 사이에 조사·발견·대응·관점 전환을 넣었다. 플레이 시간 목표 달성이나 충분한 분량인지는 실제 사용자 플레이 후 판단해야 한다. |
| 비주얼 | 밤의 방을 다시 그렸고 소품·조명·시간의 흔적을 추가했다. 후드티와 정장을 구분해 그린 옷장, 호떡이 사진을 크게 보는 장면을 추가했다. |

## 읽기와 입력

- 데스크톱에서는 그림과 글을 나란히 배치했다. 작은 화면에서는 상황 설명을 먼저 읽고 장면 속에서 행동한다.
- 새 장면 직후 480ms 동안 입력을 받지 않는다. 이전 장면의 입력, 더블클릭의 추가 클릭, 누르고 있는 Enter/Space의 반복 입력도 막는다.
- 조작은 마우스·터치 외에 Tab과 Enter로 진행할 수 있다. 돌돌이는 Space/Enter로 한 줄씩 민다.
- 장면을 바꿀 때 포커스를 제목으로 옮긴다. 도움말과 다시 시작 확인 창은 포커스를 안에 유지하며 Escape로 닫을 수 있다.
- 움직임 줄이기 설정을 존중한다. 새 조작에 제한시간·숙련도 점수·추가 관계 보상은 붙이지 않았다.

## 규칙 변경 범위

- v4.1의 열 밤, 월급·고정비·돌돌이·사료 비용, 관계 계산과 엔딩 판정 7개는 유지했다.
- 사장님이 오는 아침에도 돌돌이를 건너뛸 수 있다. 이 경우 리필을 청구하지 않고, 털이 남은 출근으로 처리한다.
- 멀어진 관계의 엔딩에서 고양이는 사료를 먹는다. 먹고도 사람에게 다가오지 않는 행동으로 관계를 표현한다.
- v4.1의 비용 규모와 회사 평가가 월급에 미치는 방식은 이번에 재조정하지 않았다. 현실적인 납득도와 게임 균형은 별도 검토 대상이다.

## 확인한 것

- `node --test tests/experience-flow.test.cjs`: 5개 검사 통과. 실제 규칙 코드와 화면의 액션을 사용해 1,024개 선택 조합을 끝까지 진행했고, 열 밤의 기록과 엔딩 7개 도달을 확인했다. 이는 DOM 모형을 쓰는 로직 검사이며 시각 검증은 별도다.
- 브라우저 한 경로를 시작부터 ‘사랑만으로는’ 엔딩까지 진행했다. 옷장·후드티, 비 오는 밤, 호떡이, 문 드래그, 키보드 돌돌이를 확인했다. 이 경로에서 콘솔 오류와 경고는 없었다.
- 1280px 데스크톱과 390px 모바일 화면을 확인했다. 모바일 밤 화면의 가로 넘침과 화면 밖 선택지는 없었다.
- 사용자가 설명 없이 플레이했을 때의 이해도·감정·충분한 분량은 아직 확인하지 않았다. 자동 플레이의 통과가 이 부분의 검증을 대신하지 않는다.

## 검토할 부분

첫 세 밤에서 주인공과 고양이의 사정을 이해하고 선택하는지, 옷장의 발견이 다음 밤의 행동을 바꾸는지, 호떡이 장면의 반전이 전달되는지부터 본다. 그 결과를 토대로 분량·사건·수치·그림을 다음 차례에 다듬는다.
