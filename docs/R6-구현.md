# R6 생활·입력 변경

커튼은 실제 손잡이를 잡고 닫거나 열며, 날씨 때문에 닫았던 커튼은 다음 아침에 다시 열린다. R4/R5 저장을 복구할 때 진행 잠금과 빠진 카메라/생활 필드를 정리한다. 소파·물·밥·고양이·인형의 실제 클릭 지점을 구분하고, HUD/대화 길이로 월드가 이동하지 않도록 상태·대화 영역을 따로 예약한다.

침실은 일반 방의 가로 침대·빨간 조명·단순 책상·도시 창을 모든 취침/기상/겨울 장면에서 공유한다. 선택한 첫 교정본의 인물/청소/습식/기본돌봄/승객/가로침대 v2 PNG6종과 기존 기기/그릇/빈 기기3종은 `assets/r6-asset-manifest.json`과 `r6-prompts.md`에 기록되어 있다. 인물/그림 변경 검증은 그래픽 담당의 결과를 인수했으며 게임 검증에서 같은 장면 검사를 반복하지 않았다.

상담 수당8,000원+계약 수당8,000원/고객을 매일 지급한다. 지각은 고객당 분당200원(최대3,000원) 상담 수당을 줄이고, 20분 초과·털·실제 옷 냄새·수면 부족은 계약의 구체적인 보류 이유가 된다. 추가 상담은 수입과 귀가60분 지연을 함께 준다. 첫 근무는 일찍 일어나 준비할 수 있으며, 이후도 밥15+물8+옷7=30분으로 기본 준비가 가능하다.

슈퍼의 용품 선반에서 자동 화장실54,000 / 급식기42,000 / 정수기28,000 / 청소기48,000 / 고급 장난감24,000원을 구매한다. 기존 돌봄 장소를 대체하며 소유·급식기 사료·정수기 물·수거함·장난감 내구도가 저장된다. 기본 장난감은65분(해진 마지막은95분), 고급은16분이며 각각3회/18회 후 실제 교체가 필요하다. 기기를 사도 애정이나 접촉이 자동으로 늘지 않는다.

바닥 털2·먼지1이 매일 쌓이고, 쓸기18분·물걸레질24분 또는 로봇청소기로 정리한다. 모래 냄새는 실제 청소일과 하루 방치 여부를 보고 옷과 상담에 이어진다. 매일 저녁 치운 모래가 다음 아침 바로 심한 냄새로 돌아오지 않는다. 환기·청소·깨끗한 옷으로 수습한다.

`node tools/r6-balance.cjs`는 모델 밖 돈이나 시간을 보정하지 않고 13일/근무10일의 방치·과도한 아침 노동·효율 수동·복장 양보·투자 정책과 추가 상담 경로를 비교한다. 결과는 `.preview/r6-balance.json`에 생성한다. 수동으로 끝까지 계약과 정시 출근을 지킬 수 있으며, 매일 추가 상담까지 받으면 늦은 놀이/청소가 겹친 밤에는 취침 전 여유가4분으로 줄어든다. 투자는 같은 최대 수입 경로에서 최소101분의 여유를 만든다.

진동은 `assets/audio/phone-vibration.wav`를 Start/Continue 제스처 후 WebAudio에 연결하고 `G.phoneBuzz`와 함께 시작한다. 웹 빌드에는 캐시 구분 URL, 단일 HTML에는 음원 데이터가 포함된다. 검증에서는 오디오 장치 대신 WAV와 스케줄 연결만 확인한다.

검증은 실제 HTML/상태/입력을 사용하는 메모리 DOM, 실제 Canvas PNG, 빌드·공개 파일 해시로 한다. 사용자 화면·브라우저·소리 재생을 사용하지 않는다. 실제 브라우저 계산 레이아웃·주관적인 난이도·감정 전달을 자동 검증했다고 주장하지 않는다.


2026-11-04 스타일 재수정 후 로컬 준비: `node tools/r6-v2-review.cjs`는 현재 게임 입력의 새 돌봄·걷기·저장 재개와 최종 자산/빌드 해시만 확인한다. 반려 인물·미사용 R5 세로침대/사람/돌봄·생성 source/proof는 로컬 웹/단일 HTML의 로드 목록과 파일 묶음에서 제외한다. 원본은 저장소에 보관한다. `.preview/r6-v2-review/report.json`과 집/지하철/습식 PNG, `dist/downloads/Cat-at-the-Door.html`이 검토 결과다. 이전 경제·13일/전체 기능 검사는 반복하지 않았다. 스타일 선택을 배포 승인으로 해석하지 않으며 원격 추가 푸시·공개·승인 재시도는 보류한다.
