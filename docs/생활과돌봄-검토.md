## 현재 규칙

평일 저녁은 큰 활동 두 칸, 주말은 네 칸이다. 야근·가방 누락·미완성 업무로 늦어진 날은 한 칸이 남는다. 밥과 물은 큰 활동 칸을 쓰지 않는다. 설거지를 포함한 주말 집안일은 한 칸씩 사용한다.

회사 파일 분류는 2일과 9일만 직접 한다. 가방 준비는 노트북·충전기·수첩을 넣는 조작이며 집에서 회사 과제를 풀지 않는다. 추가 업무를 오늘 할지 내일 할지 고른 결과는 실제 귀가 시간에 반영한다.

아침과 저녁 돌봄을 따로 기록하고 밤중 보충은 다음 아침 식사나 시간을 대신하지 않는다. 놓친 식사는 상태를 악화시키지만 다시 먹이고 돌보면 회복된다. 예전에 한 번 놓친 일 때문에 나중에 갑자기 종료시키지 않는다. 상태 수치와 엔딩 기준은 화면에 공개하지 않는다.

## 검사와 미확인 사항

이번 상태·서사 검사 24개와 입력 흐름 검사 14개, **총 38개가 통과했다.** 실행 명령은 다음과 같다.

```sh
npm test
```

검사한 내용은 활동 칸과 주말 시간대, 날짜별 파일의 대응, 첫 구매 문구와 식량 예산, 가방 준비·누락, 정상 퇴근과 야근, 추가 업무를 미룬 날의 결과, 미완성 업무 이월, 밤·아침 돌봄 분리, 반복 누락과 회복, 돌돌이 유지, 두 주 진행과 서로 다른 결과, 팀장 대사다.

입력 검사는 실제 HTML에 없는 요소를 임의로 만들어 통과시키지 않는다. 실제 조작·상태·서사·렌더 코드를 함께 실행하고, 렌더 좌표의 유효성도 검사했다. 프롤로그부터 열두 날짜, 주말 집안일, 첫 회의와 마지막 행동까지 연결했다. 시작 전 무음과 시작·이어하기 후 소리, 첫 구매 화면, 넓은 대화창 클릭, 문 드래그의 양쪽 선택, 저장·초기화, 가방 준비, 날짜 분류, 새벽 급식, 놀이와 지속 쓰다듬기도 확인했다.

마지막 장면은 글을 읽고 기다리기만 하면 끝나지 않는다. 쌓인 결과에 따라 손을 내밀거나 물을 채우거나 소파에 앉는 마지막 행동을 한다. 이 행동 하나가 과거의 돌봄 누락이나 관계를 지우지 않는 것도 검사했다.

실제 Canvas로 침실 아침·수면, 거실, 열린 문·닫힌 문, 가방·쓰다듬기·설거지, 문 밖 고양이 화면을 만들어 확인했다. 사용자 요청에 따라 컴퓨터 화면이나 브라우저를 조작하지 않았고, 실제 소리를 재생하지 않았다. 자동 검사와 정지 화면 확인을 재미나 감정 전달에 대한 사용자 승인으로 간주하지 않는다.

## 파일과 배포

현재 소스는 `src/`, 그림과 글꼴은 `assets/`, 현재 문서는 `docs/`에 있다. 이전 자료는 `archive/v4/`와 `archive/r2/`에서 보관한다.

수정 소스는 `codex-v5`에 반영하고 공개 게임은 `https://kohyuji.github.io/cat-at-the-door/codex-v5/`로 배포한다. 기존 main 소스와 기존 공개판은 유지한다. 웹 배포 도구와 순서는 [배포 안내](배포안내.md)에 있다.
