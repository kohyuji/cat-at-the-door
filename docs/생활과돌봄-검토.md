# 생활과 돌봄 개편 검토 기록

## 바꾼 이유

이전 검토본은 시작의 글과 버튼을 고쳤지만, 플레이가 계속 문·돌돌이·결말의 짧은 순환에 묶여 있었다. 이번에는 생활 속 행동, 회사에서 실제 맡은 일, 고양이가 남긴 흔적이 서로 영향을 주도록 새 진입점과 상태 모델을 만들었다.

## 구현한 연결

1. 구조한 뒤 이름 짓기 → 후드티에 털이 남음 → 함께 지내는 시간 → 채용 연락과 첫 출근 전날.
2. 집 두 공간에서 이동·돌봄·준비·휴식 → 직접 문틈과 이불을 조절 → 아침의 옷·인형·자리.
3. 아침 옷과 가방 → 열차 도착·탑승·차내 이동·하차 → 회사 사람들과 대화·자료 정리 → 퇴근과 귀가.
4. 2일 자료 위 고양이는 상자에 옆자리를 만들거나 책상 밖으로 안내할 수 있다. 옆자리는 15분이 들며 이후에도 남는다.
5. 첫 폭풍의 기척은 고양이의 움찔함·창문의 흔들림·비·번쩍임·방향 소리로 보인다. 창문을 닫는 동작과 곁에 30분 앉는 행동은 분리했다. 후드티와 평소 접촉이 있으면 두 번째 폭풍의 대응도 달라진다.
6. 닫힌 문 뒤 고양이는 인형이나 익숙한 냄새의 옷을 찾는다. 고양이를 조작한 보상 점수 대신 물건·털·눌린 천이 다음 아침에 이어진다.
7. 사장 대화는 실제 업무 검토와 내일의 약속 뒤 호떡이 사진으로 이어진다. 동기 대화가 먼저 단서를 준다. 고양이를 좋아한다는 사실이 업무 책임이나 정장 손질을 무효화하지 않는다.
8. 사료가 줄어드는 때마다 보유량을 확인할 수 있고, 작은 봉지와 무료로 나눠 받기가 있다. 고정 급여는 첫 안내·가방·월급날에 같은 금액으로 보인다.

## 판정과 화면이 어긋났던 부분

- 돌돌이의 한 면에 일부만 붙었는데 화면에서는 모든 털을 없애던 처리를 수정했다.
- 실제 업무 미니게임을 완료한 경우는 사전 준비가 없어도 미완료가 아니다. 준비·피로는 결과의 여유와 추가 소요 시간에 반영한다. 미완료로 퇴근하는 선택은 별도 기록한다.
- 아침에는 긴 준비·휴식·놀이를 열어 저녁의 시간 제약을 우회하지 않는다. 기본 돌봄 등에 쓴 아침 시간은 시계에 표시한다.
- 주말 출근과 중복 귀가에 의한 시간 초기화를 막았다.
- 커튼 닫기 자체는 0분이다. 남은 시간이 적다고 창문조차 못 닫게 하지 않는다.
- 인형 발견 알림은 매일 재생하지 않으며, 정장을 보관한 고양이 관점에도 후드티의 몸 자국이 다음 아침에 남는다.

## 확인 범위

`node --test`는 순수 상태 판정과 실제 DOM 입력 처리·애니메이션 시계를 사용하는 전체 흐름을 확인한다. 구조·이름 짓기·생활 동작·닫힌 문 밖 행동·출퇴근·날짜별 회사 대화·책상 방해·사료 구입·호떡이 대화·주말·월급날·마지막 밤까지 진행한다. 실제 렌더 코드도 함께 실행한다. Canvas의 픽셀 품질과 소리의 감정적 전달력은 자동 검사로 판정하지 않는다.

브라우저에서는 프롤로그, 이동·대화 타이핑, 사료를 끌어 붓는 동작과 그릇·시계 변화, 집과 회사의 비율, 열린 문 너머 공간, 도구와 잠자리 그림을 확인했다. 장면별 확인용 파일은 상위 작업공간 `.preview/life-playtest.html`이며 `node tools/build-playtest.cjs`로 새 코드에서 생성한다. 이 파일의 장면 바로가기는 검사용이고 일반 검토본에는 없다.

## 남은 판단

사용자가 요구한 ‘더 큰 경험’에 충분한지, 일상의 반복이 어느 지점에서 지루해지는지, 고양이 관점과 호떡이 장면의 의도가 플레이 중 이해되는지는 실제 플레이 피드백이 필요하다. 클릭 수나 테스트 개수로 이 부분까지 해결했다고 주장하지 않는다. 픽셀 배경과 인물 사이의 그림 밀도도 사용자 취향에 맞는지 검토 대상이다.

원격 푸시·main 반영·공개 배포는 하지 않는다. 과거 v4/v5는 별도 이력으로 보존한다.
