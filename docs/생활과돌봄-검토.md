# 2026-11-04 피드백 반영 기록

## 진행과 조작

중앙의 E 버튼과 E로 미니게임을 대신 완료하는 기능을 제거했다. 이동과 사물 조작을 구분하며, 다음 사물에는 화살표와 테두리를 표시한다. 첫 출근에는 사람들에게 인사하고 업무를 확인한 뒤 실제 작업과 확인을 거쳐야 퇴근할 수 있다. 이후의 출퇴근은 반복 탑승·하차를 요구하지 않는다.

아침 이불 정리·옷 입기·가방 챙기기는 실제 완료 상태와 시간을 가진다. 침대 정리는 이불과 베개가 움직이고, 가방은 손에 든 그림으로 보인다. 챙기지 않고 떠나면 돌아가거나 공용 노트북을 빌리는 선택을 해야 한다. 아침 커튼은 열고 낮의 하늘을 표시한다. 주말은 오전 10시부터 시작하며 낮에 침대를 잘못 눌렀다고 즉시 하루가 끝나지 않는다.

잠자리는 방문을 열고 잘지 닫고 잘지 고른다. 문손잡이로 틈의 수치를 조절하지 않는다. 닫힌 문 밖 고양이를 조작하는 장면에서는 사람을 거실에 그리지 않는다. 인형을 옮긴 결과는 아침에 실제 물건과 확인창으로 연결한다.

## 그림·소리·UI

- 우산의 문제는 배경과 비슷한 색이었다. 우산을 주황색으로 바꾸고 기울이는 동안 사람과 팔을 유지했다.
- 고양이 초상화는 넉넉한 80×80 영역에 맞춰 그린다.
- 쓰다듬기·수면은 따로 생성한 투명 PNG 프레임으로 교체했다. 수면은 고양이 유무를 나눠 중복 합성하지 않는다.
- 몽타주에서도 한 사람과 한 고양이만 표시한다. 회사 동료는 사무실 옷을 입고, 열차에는 주인공의 팀장·동료 대신 일반 승객이 있다.
- 정장 털은 옷 모양 내부에 배치한다. 접착면을 벗기는 조작도 별도 상자 대신 실제 롤 원통의 탭에 있다.
- 소리는 기본 꺼짐이다. 스피커 버튼을 직접 누르기 전에는 AudioContext도 만들지 않는다. 사용자 지적 직후 내가 연 브라우저와 로컬 서버를 닫았고 다시 열지 않았다.
- 휴대폰은 기기 모양과 알림 배지를 가진다. 남은 사료·시각·피로 상태는 항상 보인다. 중요한 사료 부족은 확인할 때까지 남는다.
- 채용 결과·첫 출근 안내는 휴대폰에서 읽으며 휴대폰을 사람처럼 말시키지 않는다. 겨울 표제는 하나다. 둥근모꼴을 본문·대화·전화·엔딩에 통일했다.

## 일과 돌봄을 묶은 규칙

평일 저녁에는 식사·샤워를 마친 뒤의 시간이 남는다. 밥과 물을 챙기고 준비·놀이·휴식 중 할 일을 고른다. 세 가지를 매일 모두 하도록 만드는 순서가 아니다.

내일 쓸 메모를 준비하고 가방에 넣으면 실제 원본·단서를 바로 쓸 수 있다. 준비하지 않았으면 원본을 찾는 데 15분과 검수 기회를 쓴다. 피로·지각·노트북 대여는 다음 날의 시간과 검수 기회에 반영된다. 손속도나 드롭 실패로 자원을 차감하지 않는다. 전날 빠뜨린 항목을 고치면 해당 항목만 사라지고, 그대로 두면 계속 남는다.

회사에서는 날짜별 파일 정리, 다섯 행 합계 입력, 틀린 첫 장 수정, 옛 종이 제외, 확인본 전달을 한다. 원본을 보고 판단해야 하며 아무 카드나 꽂아 넣고 완료할 수 없다. 계산에는 실제 숫자 입력을 쓴다. 준비 메모는 그날 알 수 있는 내용만 포함하며 미래의 변경 공지를 미리 주지 않는다.

배고픔·갈증·문 앞 울음·밤중 이불 장난은 실제 밤 장면과 다음 아침 피로로 이어진다. 밤에 보충한 밥·물은 아침 시간을 소모하지 않으며 이미 설친 잠까지 지워 주지 않는다. 익숙한 자리와 놀이가 있으면 문을 닫고도 지낼 수 있다. 책상 옆 상자를 마련하면 이후 준비 시간이 줄어든다.

첫 구조 때 사료 주문을 경험한다. 이후 휴대폰으로 익숙한 사료와 좋아하는 습식을 고른다. 습식은 비싸지만 그날 놀이에 빨리 반응해 놀이 시간이 줄어든다. 영구 애정 점수를 사는 방식은 아니다. 동료에게 사료·돈을 부탁하는 흐름, 임금과 중도 입사 정산, 접착면 재고는 제거했다.

사용자가 거절한 별도 상품 설정과 관련 용어, 호떡이 에피소드도 현재 실행 경로에서 제거했다. 사무실 대사는 실제 화면의 날짜·파일·틀린 숫자·도착 시각을 가리키도록 다시 썼다. 같은 인물에게 자동으로 대화를 다시 시작시키지 않는다. 엔딩은 실제 업무·관계·피로에 맞는 짧은 문장으로 쓴다.
