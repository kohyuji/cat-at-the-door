# 시작 구간 재검토

2026-11-03 · `codex/v4-experience`

이전 검토본은 시작의 과도한 주제 설명, 겹치는 제목, 상시 사물 이름표, 행동 결과 없이 넘기는 진행 때문에 사용자가 거절했다. 이번 검토 범위는 시작부터 첫날 밤까지다. 후반 사건과 경제 규칙의 추가 개편은 별도 작업이다.

## 이번에 고친 것

- 시작 화면에는 `Cat at the Door`, 플레이어 이름, 시작만 둔다. 작품 소개·주제·과목명·부제는 넣지 않는다.
- 우산을 기울이면 손을 축으로 우산이 이동하고, 고양이가 비를 피하며 다가온다. 결과 화면은 다음 행동을 하기 전까지 남는다. 최소 1.8초 동안 다음 입력도 막는다.
- 고양이 이름은 데려온 뒤 집에서 짓는다. 이름을 부른 다음 고양이에게 손을 내미는 흐름으로 잇는다.
- 회색 후드티를 크게 보여 준다. 쓰다듬으면 고양이가 몸을 비비고 그 뒤 천 위에 털이 나타난다. 결과가 보인 뒤 벽 스위치로 불을 끈다.
- 취업은 합격 문자와 정장으로 전달한다. ‘첫 출근 전날’이라는 시간 정보는 한 곳에 크게 둔다.
- 첫날 밤에는 문손잡이와 이불을 직접 선택한다. 상시 글자 버튼·사물 이름표·반복되는 소제목·소개용 머리말·푸터는 제거했다. 접근성 이름과 키보드 포커스는 유지한다.
- 문을 열면 고양이가 방 안으로 들어오는 움직임이 있고, 이불을 선택하면 얼굴 쪽으로 올라온다. 첫 조작을 못 찾고 머무를 때만 짧은 안내를 표시한다.
- 머리를 공통 SVG 조각으로 맞추고, 머리 위 피부 띠와 목의 틈을 고쳤다.

## 확인 범위

- 브라우저에서 새 프롤로그를 처음부터 첫날 밤까지 진행했다. 이름 입력, 우산, 고양이의 반응, 후드티와 털, 전등, 합격 문자, 정장과 첫 문닫힘을 확인했다.
- 9개 코드 검사 통과. 결과 유지 시간, 제목과 이름 입력 단계, 접근성 이름, 입력 방어를 확인했다. 별도로 1,024개 코어 선택 조합에서 열 밤과 엔딩 7개 도달을 유지했다.
- 정지 이미지로 제목 중복 제거, 기울어진 우산, 후드티의 털, 머리와 목의 연결도 확인했다. 이 검사는 감정 전달과 재미에 대한 사용자 판단을 대신하지 않는다.

## 이어지는 작업

사용자의 시작 구간 검토를 받아 수정한 다음 후반 장면을 같은 기준으로 검토한다. 기존 검토본의 구현이나 자동 검사 통과를 사용자 승인으로 간주하지 않는다.
