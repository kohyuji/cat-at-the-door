# 최종 사용 프롬프트와 사용자 확정

후속 확정: 도시의 중성 회색/먹색/바랜 청색, 슈퍼의 제한된 적갈색. 월드 주인공은 연회색 후드티·연청바지·적갈색 끈, 정장은 짙은 남색과 흰 셔츠. 인물·고양이는 저해상도 픽셀 군집으로 재제작. 앉기 전용 아틀라스는 의자 접촉을 포함한다.

초상화는 사용자가 첨부로 확정한 `r4-portraits-approved.png`가 얼굴 원본이다. `r4-portraits-approved-cords.png`는 첫 셀의 후드티 색/끈 보정본이며, 런타임은 원본의 모든 얼굴과 나머지 일곱 셀을 사용하고 첫 셀 y=330 아래 의상만 보정본으로 합성한다. 피곤한/평범한/웃는 얼굴 시안은 최종에 사용하지 않는다.

최종 경로/셀/해시는 `r4-asset-manifest.json`, 로더 키는 `PixelArt.assetSources`가 기준. 초기 PNG를 덮어쓰지 않았다. 모든 신규 생성/수정은 built-in `image_gen.imagegen`, 승인 첨부 원본은 바이트 그대로 복사했다. 프롬프트의 지정 크기와 실제 생성 크기는 다를 수 있으며 manifest의 실제 크기가 우선한다.
