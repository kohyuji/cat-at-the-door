# 픽셀 배경

이 프로젝트용으로 이미지 생성 도구에서 만든 배경이다. 배경에는 인물과 조작하는 물건을 굽지 않고, Canvas 스프라이트와 상태를 따로 겹친다.

| 파일 | 구성 | 원본 생성 파일 |
| --- | --- | --- |
| `rooms-pixel.png` | 같은 크기 2패널: 침실 / 부엌 겸 거실 | `exec-ec63fa6e-357a-48b1-9ee2-e07181812fbb.png` |
| `places-pixel.png` | 같은 크기 3패널: 겨울 거리 / 지하철 승강장 / 회사 | `exec-e1742342-cdb5-4b0a-b6c3-0c0b69419c46.png` |

제작 방향: 작은 임대 주택, 침실과 부엌은 문으로 분리, 낮은 침대·접이식 책상·작은 소파, 귀여운 픽셀 비율. 회색·아이보리·파랑·청록을 사용하고 누런 핑크의 전체 색조와 사실적인 낡음은 피했다. 회사·역·거리는 같은 표현 밀도와 색을 사용한다. 회사 사람·주인공·고양이와 실제 상호작용 소품은 `pixel-render.js`에서 그린다.
