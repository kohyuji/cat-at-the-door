# 픽셀 이미지와 스프라이트

이 프로젝트용으로 이미지 생성 도구에서 만든 배경이다. 배경에는 인물과 조작하는 물건을 굽지 않고, Canvas 스프라이트와 상태를 따로 겹친다.

| 파일 | 구성 | 원본 생성 파일 |
| --- | --- | --- |
| `rooms-pixel.png` | 같은 크기 2패널: 침실 / 부엌 겸 거실 | `exec-ec63fa6e-357a-48b1-9ee2-e07181812fbb.png` |
| `places-pixel.png` | 같은 크기 3패널: 겨울 거리 / 지하철 승강장 / 회사 | `exec-e1742342-cdb5-4b0a-b6c3-0c0b69419c46.png` |

제작 방향: 작은 임대 주택, 침실과 부엌은 문으로 분리, 낮은 침대·접이식 책상·작은 소파, 귀여운 픽셀 비율. 회색·아이보리·파랑·청록을 사용하고 누런 핑크의 전체 색조와 사실적인 낡음은 피했다. 회사·역·거리는 같은 표현 밀도와 색을 사용한다. 회사 사람·주인공·고양이와 실제 상호작용 소품은 `pixel-render.js`에서 그린다.


## 추가 자세 프레임

`poses-with-cat.png`와 `poses-solo.png`는 이미지 생성 도구의 built-in 모드로 제작한 4열×2행 투명 PNG다. 윗줄은 무릎을 꿇고 쓰다듬는 자세 4장, 아랫줄은 이불을 덮고 자는 자세 4장이다. 아랫줄에서 고양이가 함께 자는 경우와 없는 경우를 구분한다. 코드에서 필요한 프레임을 잘라 반복하므로 이미지로도 애니메이션할 수 있다.

정확한 제작·수정 프롬프트는 [poses-prompts.json](poses-prompts.json)에 있다. 원본 생성 파일은 각각 `exec-67b4e972-9f45-47f9-8a54-99964200fefd.png`, `exec-347b5d4d-4b93-482d-9b90-bc825bd2b349.png`이며 선택한 파일을 저장소에 복사했다. 배경 PNG와 자세 PNG·글꼴은 단일 파일 검토본 안에도 포함한다.
