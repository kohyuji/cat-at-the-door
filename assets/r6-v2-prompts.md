## 내보내기

원본 RGBA를 point sampling으로48×64 logical cell에 추출한다. 색상 quantization/blur/alpha threshold/손 재도색은 사용하지 않는다. 런타임 정수4배, 돌봄 근접 정수8배. 프레임별 source crop/anchor/ratio와 그릇 offset은 최종 r6-asset-manifest.json에 기록한다. 침대는 새 source 그대로 기존228×120 자리만 대체한다. 기존 반려 PNG·참조 PNG는 보존하며 runtime assetSources에서 제외한다.
